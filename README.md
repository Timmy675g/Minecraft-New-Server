## SurvivalKendy

SurvivalKendy is a community driven Minecraft SMP focused on long term survival gameplay, technical experimentation, and community interaction.

The server is built around stability, transparency, and continuous improvement while maintaining a fun and active environment for both Java and Bedrock players.

Funfact : This server name came from one of my friend name as a joke because his real name is almost sounded like "Candy" so we named it "Kendy"

---

# Philosophy

SurvivalKendy prioritizes:
- Community first decisions
- Fair gameplay
- Transparent maintenance and incident reporting
- Long-term sustainability
- Continuous technical experimentation and learning

The server is actively maintained and self hosted using modern infrastructure tools and cloud technologies.

---

# Features

- Java + Bedrock crossplay support (Geyser/Floodgate)
- Fabric based server
- Dockerized infrastructure
- Automated backups
- Server status monitoring
- Community focused administration
- Optimization focused mod stack
- Maintenance transparency and incident tracking

---

# Infrastructure

Current stack includes:
- Docker
- Fabric
- Geyser + Floodgate
- NGINX
- Cloudflare
- Spark Profiler
- Automated backup systems
- VPS based deployment
